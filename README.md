# Tim's Book Nook

I've always loved getting lost in a good book, and this is where I write about it: reviews, interesting concepts a book covers, and the occasional opinion piece. This blog also serves as my project for Project: Getting
started in Web Programming at IU.

## Status

Concept phase. Development has not started yet.

## Planned tech stack

- Backend: Python 3, Flask, Jinja2 templates
- Database: SQLite (Python's built-in sqlite3 module)
- Frontend: HTML5, Tailwind CSS, plain JavaScript
- Content editing: Quill (WYSIWYG editor)
